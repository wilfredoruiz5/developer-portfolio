## Getting Started

To run the Angular demo locally:

```bash
git clone https://github.com/wilfredoruiz5/developer-portfolio.git
cd developer-portfolio/angular-demo
npm install
npx ng serve
```

Open `http://localhost:4200/` in your browser.
